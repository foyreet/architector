# Интерфейс локальной версии

Главный сценарий: пустая схема → свои данные → запуск → результаты.
Создание схемы и AI Chat находятся в боковом меню. Каталог «+» объединяет блоки,
проекты и сохранённые данные. «Мои блоки» содержит подтверждённые собственные
блоки, «Библиотека» — встроенные. Облачный поиск отсутствует.

Обучение — справочник с поиском. Готовых учебных проектов и датасетов нет.
AI Chat при первом открытии показывает настройку собственного подключения.
MCP объясняется отдельно: диалог идёт во внешнем AI-клиенте.

Русские подписи, видимый фокус клавиатуры, модальные окна с Escape, прокрутка
длинного содержимого и сохранение введённых настроек при ошибке обязательны.
Проверяйте изменение на 1440×900 и 1024×768, при затронутом мобильном сценарии —
также на узком экране. Используйте только временные данные.
